# 🚀 Meu Portfólio - Kelvin Henrique  

Bem-vindo ao meu portfólio! Sou um **Desenvolvedor Fullstack** formado pela DNC, apaixonado por tecnologia e inovação. Atualmente, curso **Bacharelado em Estatística** na UEPB e estou sempre em busca de novos desafios e aprendizados.  

## 🌟 Sobre o Projeto  

Este é o meu portfólio pessoal, desenvolvido com **React.js** e utilizando animações com **Framer Motion**. O objetivo é apresentar minhas habilidades, projetos e formas de contato de maneira profissional e interativa.  

## 🔧 Tecnologias Utilizadas  

- **Front-end:** React.js, CSS Modules, Framer Motion  
- **Design & UI:** Figma  
- **Versionamento:** Git e GitHub  
- **Hospedagem:** [Vercel](https://vercel.com/)  

## 📌 Funcionalidades  

✔️ **Navbar interativa** para facilitar a navegação  
✔️ **Apresentação profissional** com animações suaves  
✔️ **Seção de habilidades** destacando minhas competências técnicas  
✔️ **Projetos em destaque** com links para repositórios no GitHub  
✔️ **Formulário de contato** com integração ao WhatsApp  
✔️ **Links diretos** para LinkedIn, GitHub e currículo  

## 🚀 Como Rodar o Projeto  

Para rodar o projeto localmente, siga os passos abaixo:  

 1. Clone o repositório:
   ```sh
   git clone https://github.com/KelBaker/portifolio.git
   ```
2. Acesse a pasta do projeto:
  ```sh
  cd portifolio
  ```
3. Instale as dependências:
  ```sh
  npm install
  ```
4. Inicie o servidor local:
  ```sh
  npm start
  ```
5. Acesse o site no navegador:
  ```sh
  http://localhost:3000
  ```
